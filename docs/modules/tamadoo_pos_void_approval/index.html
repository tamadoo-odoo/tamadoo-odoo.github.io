Require a manager PIN to void an order line at the Point of Sale.

What it does

Stop unauthorized voids at the register. This module adds a Void button to the POS order controls. Voiding the selected line requires the manager PIN configured on the Point of Sale — a wrong PIN blocks the void.

Key features

  • Void control button on the order screen.
  • Manager PIN prompt before a line is removed.
  • Wrong PIN is rejected with a clear message.
  • Leave the PIN empty to disable the protection.

How to use — step by step

1. Set the void manager PIN

Point of Sale → Configuration → Settings → Pricing → Void Manager PIN.

2. Select the line to void at the POS

3. Tap "Void" in the Actions menu — the manager PIN is required

Tap the ⋮ button next to the control buttons to open Actions, then tap Void.

Requirements

  • Odoo 20 — Point of Sale (point_of_sale).
