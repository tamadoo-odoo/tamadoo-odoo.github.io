Paste a link, click Fetch — the image is downloaded for you.

What it does

Set product images without downloading and re-uploading files. Open the Image from URL tab on any product, paste an image link, and click Fetch — Odoo downloads it and sets it as the product image.

  • Works with most image hosts (sends a normal browser user-agent).
  • Perfect for bulk catalog setup from supplier image links.
  • No external dependencies.

How it looks

Step by step

1. Open the product

Open a product and go to the Image from URL tab.

2. Paste the link

Paste the address of the picture in Image URL.

3. Fetch

Click Fetch image from URL. The picture is downloaded and set as the product image. If the link is not an image you get a clear error.

Requirements

  • Odoo 16 / 17 / 18 / 19 / 20 — Community or Enterprise.
  • Depends on product.
