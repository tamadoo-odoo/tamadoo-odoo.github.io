Remove the internal reference code from product names on purchase order lines.

What it does

By default Odoo prints the internal reference in front of the product name on every purchase order line — for example [DESK-0001] Office Desk. This module removes that [CODE] prefix from purchase orders and requests for quotation, both in the product cell and the line description, so the lines read cleanly as Office Desk.

Key features

  • Hides the [INTERNAL_REF] prefix from product names on purchase order lines.
  • Cleans both the product cell and the auto-filled line description.
  • Display-only — the internal reference itself is never changed.
  • Zero configuration: it works the moment it is installed.

How to use — step by step

1. Before — the internal code clutters the line

On a normal purchase order the line shows [DESK-0001] Office Desk.

2. After — install the module, the code is gone

The same line now reads simply Office Desk.

  • Odoo 20 — Purchase (purchase).
