Warn the cashier when a customer has an outstanding balance.

What it does

Loads each customer's outstanding receivable balance into the POS. When a customer who owes more than the configured credit limit is selected, the cashier gets a clear warning — so you don't unknowingly extend more credit.

Key features

  • Real outstanding balance shown in the warning.
  • Configurable credit limit per Point of Sale.
  • Sticky warning so it isn't missed.
  • Enable / disable per Point of Sale.

How to use — step by step

1. Configure the warning

Point of Sale → Configuration → Settings → Pricing → Customer Debt Warning.

2. Select a customer who owes you

Requirements

  • Odoo 20 — Point of Sale (point_of_sale).
