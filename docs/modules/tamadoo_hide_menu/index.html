Pick the menus each user shouldn't see — per user, instantly.

What it does

Adds a Hidden Menus tab to every user. Choose the menu items that user shouldn't see — top-level apps or deep sub-menus — and they simply disappear for that user, with no impact on anyone else.

  • Works on any menu, app or sub-menu.
  • Per-user — never affects other users.
  • Applies immediately; fast and cache-correct.

How it looks

Pick the menus to hide on the user form

Step by step

1. Open the user

As an administrator, open Settings → Users & Companies → Users and open the user.

2. Pick the menus to hide

On the Hidden Menus tab, add the menus this user should not see. Apps and sub-menus both work.

3. Save

After the user reloads the page those menus are gone for that user. Other users see no change.

Requirements

  • Odoo 16 / 17 / 18 / 19 / 20 — Community or Enterprise.
  • Depends only on base + web. No external dependencies.
