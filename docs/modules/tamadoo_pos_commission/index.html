Track sales commission per cashier, straight from POS orders.

What it does

Set a commission rate per Point of Sale. Every line sold generates a commission record for the cashier, and a backend list totals commission per cashier — perfect for incentive schemes and payroll inputs.

Key features

  • Commission rate per Point of Sale.
  • Automatic commission record per sold line.
  • Backend list under Point of Sale > Reporting > Commissions, grouped and summed per cashier.

How to use — step by step

1. Set the commission rate

Point of Sale → Configuration → Settings → Pricing → Sales Commission.

2. Review commission per cashier

Requirements

  • Odoo 20 — Point of Sale (point_of_sale).
