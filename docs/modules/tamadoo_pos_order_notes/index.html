Add a customer note to any POS order line.

What it does

Adds an Add Note button under the POS numpad. With an order line selected, tap it to open a note dialog, type a note (e.g. "No onions", "Gift wrap"), and save it. The note is attached to that order line — it shows under the product and prints on the receipt, exactly like Odoo's native customer note.

Key features

  • One-tap note entry for the selected order line.
  • Pre-fills the line's existing note for editing.
  • Uses Odoo's standard customer-note field — prints on the receipt.
  • Zero configuration.

How to use — step by step

1. Select a line and write the note

With an order line selected, tap Add Note and type the note.

2. The note is attached to the line

The note appears under the product on the order.

Requirements

  • Odoo 20 — Point of Sale (point_of_sale).
