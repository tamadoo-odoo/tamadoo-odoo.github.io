Show the full product description in a popup from the POS product grid.

What it does

Adds a small info (ℹ) button to every product card in the POS that has a sale description. Tapping it opens a dialog with the product's full description, so cashiers can read ingredients, specs or notes without leaving the order screen. Products without a description show no button.

Key features

  • Info button appears only on products that actually have a description.
  • Full description shown in a clean dialog, without leaving the order.
  • Uses the product's Sales Description (or internal Description).
  • Zero configuration — install and it works.

How to use — step by step

1. An info button appears on products with a description

The ℹ button shows on each product card whose product has a Sales Description.

2. Tap it to read the full description

A dialog shows the product name and its full description; tap Close to dismiss.

Requirements

  • Odoo 20 — Point of Sale (point_of_sale).
