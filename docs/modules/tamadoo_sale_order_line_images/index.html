What it does

Adds the product image to your sale order lines — both in the back office and on the quotation / order PDF — so customers and staff can see exactly what's on the order.

  • Image column on the order lines.
  • Image on every line of the printed quotation.
  • Pulled straight from the product — nothing to maintain.

How it looks

On the quotation / order PDF

On the sale order lines

Step by step

1. Give your products a picture

The image comes from the product, so there is nothing else to set up.

2. Open a quotation

The order lines show an Image column. You can hide or show it with the column selector of the list.

3. Print or send it

The quotation and order PDF has an Image column with the picture of each product.

Requirements

  • Odoo 16 / 17 / 18 / 19 / 20 — Community or Enterprise.
  • Depends on sale.
