POS Category Discount - POS Discount Approval by PIN

Apply percentage discounts to all order lines that belong to a specific POS category — in one tap. Rules can require a manager PIN for approval, making it safe for promotions without giving cashiers free rein.

  • Configure multiple discount rules per category (e.g. Food 10%, Electronics 5%)
  • Optional manager PIN per rule
  • 🏷 Category Discount button at the bottom of the POS order panel
  • Discount applied instantly to all matching lines
  • Rules managed in Point of Sale → Orders → Category Discounts

Step by step

1. Create the discount rules

Open Point of Sale → Orders → Category Discounts and add a line per rule: Name, POS Category, Discount %, and Require Manager PIN when a manager must approve it.

2. Set the manager PIN

Open Point of Sale → Configuration → Settings, choose the point of sale at the top and fill in Category Discount Manager PIN in the Pricing section. Left at 0, no PIN is asked.

3. Open the discount in the POS

Add products to the order, then tap 🏷 Category Discount at the bottom of the order panel.

4. Choose the rule

Select the rule. If the rule requires it, enter the Manager PIN. Then tap Apply Discount.

5. Check the order

Every line whose product belongs to that POS category gets the discount.
