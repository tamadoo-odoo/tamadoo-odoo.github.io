Set up in 5 minutes

  1. Install the module (depends on sale_management and account).
  2. Sales → Targets → Target Plans → New: name, period and whether actuals come from orders or invoices.
  3. Add a line per product-category group, its sales teams and their salespeople with their targets.
  4. Start the plan: actuals are computed now and every hour (or with Refresh Actual).
  5. Salespeople open Sales → Targets → My Targets; managers use Target Achievement.
